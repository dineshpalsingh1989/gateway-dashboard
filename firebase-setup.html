Server service account

The server needs a private service-account JSON file to receive and store sensor readings. Save it on the server, then enter its path here. The file contents are never sent to this page.

Test & save

The connection test checks Google Authentication, project matching, and Firestore access. It writes, reads, and removes one temporary document in _setupProbes.

Complete the Firebase checklist
  • Create a Firestore database in Native mode.
  • Enable Email/Password and any social providers you need in Authentication.
  • Add the dashboard hostname to Authentication → Settings → Authorized domains.
  • Deploy this project's firestore.rules before using the dashboard.
  • After restarting, sign in to verify browser access and permissions.

The server test uses administrative access. It cannot confirm browser security rules, social sign-in, or authorized domains. A valid API key does not confirm that the key belongs to the project ID you entered.

Storage location

Choose Firebase cloud storage or local DuckDB. Local mode stores accounts, settings, and sensor readings on this server without Firebase. Local account creation requires the administrator token.

Restart after saving. Each database retains its own data; switching does not migrate existing accounts or readings. Choose Gemini or command buttons separately in dashboard Settings.
