# Milesight Dashboard V2.0

These notes describe the current V2.0 maintenance branch. The existing v2.0.0 tag is preserved and may predate the reliability and repository updates below; use main for those updates.

Self-hosted MQTT ingestion, live sensor readings, Firestore history, and an optional Telegram assistant.

## Latest maintenance additions — 2026-10-18

- A credential-free local demo with 24 sample devices, charts, CSV export, and simulated commands (`npm run demo`).
- Seventeen additional sensor profiles using gateway-decoded JSON, with leak, level, soil, pressure, current, people-counting, temperature, tilt, and weather metrics.
- Workspace-protected MQTT downlink publication, configurable device topics, hexadecimal/Base64 previews, UC300 output presets, and owner-only command history.
- Updated Docker/installer packaging, Firestore rules, and regression tests.

Live use requires updated Firestore rules and a matching MQTT downlink topic on
the gateway's Embedded Network Server. Command publication does not confirm
sensor execution. New profiles require gateway codecs; physical hardware has
not been tested. See [the full changelog](../../CHANGELOG.md).

## Included

- Firebase setup before sign-in, JSON configuration import, connection tests, local saving, and restart status.
- Responsive setup styling with automatic dark mode and protection for unsaved edits.
- Workspace-scoped MQTT authorization and Firestore access rules.
- History charts with the latest 500 stored readings, CSV export, retry, and stale-request protection.
- Non-root Docker defaults, request deadlines, graceful shutdown, and CI-gated container publication.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/dineshpalsingh1989/milesight-dashboard/main/install.sh | sh
```

The installer prints the setup URL and administrator token. Provide your own Firebase web configuration and server service-account file, deploy firestore.rules, save settings, then restart. MQTT stays offline until Firebase is configured. The installer follows main and may install changes newer than this release; use the release tag's source for a fixed checkout.

See README.md for configuration, gateway connection, and backup instructions. Preserve data/ and the Compose .env when updating. Non-root containers must have permission to read private files and write settings.

## Validation limits

Live Firebase, gateway, and Telegram behavior requires deployment credentials and hardware. A published release does not replace deployment-specific verification.
